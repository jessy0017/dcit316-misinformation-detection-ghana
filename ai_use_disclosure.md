# AI Use Disclosure

## Tool Used
Claude (Anthropic), accessed via the Claude web/chat interface.

## Purpose and Scope of Use
AI assistance was used throughout this project for:
- Explaining and troubleshooting Python/pandas/scikit-learn code (e.g.,
  resolving file path and kernel-state errors during notebook development)
- Suggesting the structure and content of preprocessing, modeling, and
  evaluation code cells (TF-IDF vectorization, Logistic Regression baseline,
  TruncatedSVD embedding-style comparison, evaluation metrics)
- Helping interpret exploratory findings, including identifying and
  investigating two dataset label leaks (the `subject` field and the
  "(Reuters)" source-attribution string)
- Drafting the structure and prose of the accompanying research paper
  (Introduction, Related Work, Data, Methods, Results, Discussion,
  Limitations, Ethics Statement, Conclusion), based on the actual code,
  outputs, and metrics produced during the project
- Verifying academic citations against web search results before inclusion
  in the References section
- Guiding GitHub repository setup and Git workflow (repository creation,
  cloning, committing, pushing)

## What Was Verified by the Author
- All code was run by the author in their own Jupyter notebook environment;
  all reported metrics, figures, and tables reflect actual output from that
  execution, not AI-generated or estimated numbers
- All literature citations suggested by the AI were independently checked
  against web search results for accuracy before inclusion
- The author reviewed and takes responsibility for all code, analysis, interpretations, and written content in the final submission.
